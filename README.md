# KERNVIK MonitorBox

Система мониторинга доступности IT-инфраструктуры. Движок — [Uptime Kuma](https://github.com/louislam/uptime-kuma), лицензия MIT. Собственные компоненты KERNVIK разрабатываются отдельно.

## Foundation

Подготовил конфигурацию для лабораторного развёртывания Uptime Kuma в Docker Compose. Интерфейс доступен только на loopback-интерфейсе хоста. Собственная консоль, интеграция, автоматизация, резервное копирование и публичный доступ пока в плане разработки.

Требования: Linux, Docker Engine и Compose v2. Для лаборатории рекомендую 2 vCPU, 2 ГиБ RAM и 10 ГиБ свободного диска; реальные требования зависят от нагрузки и срока хранения истории.

Инструкции: [первый запуск](docs/SETUP.md), [архитектура и критерии приёмки](docs/ARCHITECTURE.md), [регламент разработки](DEVELOPMENT.md).
